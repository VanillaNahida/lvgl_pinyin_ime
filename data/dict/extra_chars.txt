# extra_chars.txt —— 字库**自定义补充字符**
#
# 用法：把你想在屏幕上显示、但 GB2312 / 日文 JIS / 输入法词典里都没有的字符
#       直接写在这个文件里即可（**不需要**每行一个，随便写、随便换行）。
#       生成字库时会被读取并并入子集：
#
#           tools/font/venv/Scripts/python.exe tools/font/gen_subset.py
#           python tools/font/gen_lvgl_font.py
#
# 规则（就三条）：
#   1. 以 `#` 开头的整行是注释，会被忽略；
#   2. **空白字符**（空格/制表/换行）会被忽略 —— 它们本来就有字形，不用列；
#   3. 其余所有字符都会被收集（重复的自动去重）。
#
# ⚠ 两点注意：
#   - 源字体（assets/fonts/DreamHanSansSC-W17.ttf）里**没有**的码位，写了也不会
#     有字形（生成时会跳过并在日志里报告数量）。想确认某个字符能不能显示，
#     看生成日志里"词典/补充表"那几行的计数，或跑起来看屏幕。
#   - 这份文件走的是**主字体（4bpp）**这一路，字多了会涨体积；只放真正需要的。
# ============================================================================
