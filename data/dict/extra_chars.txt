# extra_chars.txt —— 字库**自定义补充字符**
#
# 用法：把你想在屏幕上显示、但 GB2312 / 输入法词典里都没有的字符
#       直接写在这个文件里即可（**不需要**每行一个，随便写、随便换行）。
#       生成字表时会被读取并并入：
#
#           .\tools\venv\Scripts\python.exe tools\gen_charset.py
#           .\tools\venv\Scripts\python.exe tools\gen_font.py
#
# 规则（就三条）：
#   1. 以 `#` 开头的整行是注释，会被忽略；
#   2. **空白字符**（空格/制表/换行）会被忽略 —— 它们本来就有字形，不用列；
#   3. 其余所有字符都会被收集（重复的自动去重）。
#
# ⚠ 两点注意：
#   - 源字体（assets/DreamHanSansSC-W17.ttf）里**没有**的码位，写了也不会有
#     字形（lv_font_conv 会静默跳过）。想确认实际收了多少字，看
#     generated/font_coverage_report.txt，或跑 tools/check_charset.py。
#   - 两个尺寸的字体共用同一份字表（generated/charset.txt），字多了会一起涨
#     体积；只放真正需要的。
#
# 默认字表已经是全量的：GB2312 + UI 符号 + ASCII + 整本词库的字符集（17 265 字），
# 所以这份文件只用来补「词库里也没有」的字符。
